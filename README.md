# IS355 Networking and Cyber Security — Weekly Journal

**Student:** Colin Muller  
**Course:** IS355 Networking and Cyber Security, Loyola University Maryland  
**Term:** Fall 2026

This repository is my individual weekly journal for IS355. Each entry records the tutorial tasks for that week: the commands I ran, my own screenshots and diagrams, and my analysis and reflections on what I learned. Entries were added week by week, and the commit history shows that progress.

The journal homepage is [Main.md](Main.md). The group project is in a separate repository: [IS355_GroupProject](https://github.com/Ctmuller/IS355_GroupProject).
